How to split a PDF

  1. Select a PDF file. Drop a PDF onto the upload area, or click to browse your device. The tool reads the total page count automatically.
  2. Choose individual pages, selected pages or custom page ranges. Pick Every page separately to create one PDF per page, Extract selected pages to build a single PDF from specific pages, or Custom page ranges to define your own groupings.
  3. Split and download your PDF files. Click Split PDF. Download each output individually, or grab all of them at once in a ZIP archive with your own custom name.

What does this PDF Split tool do?

This free online PDF splitter divides a single PDF file into multiple smaller PDFs — entirely in your browser. You can split a PDF into individual pages (one file per page), extract specific pages into a single new PDF, or split by custom page ranges (one file per range). The original document stays untouched, and every output opens like a normal PDF.

The tool uses pdf-lib, a fast open-source JavaScript library that reads and writes PDF files directly. It copies page objects from the source PDF into new documents, preserving text, images, vector graphics, page dimensions and orientation. Because everything runs locally, your PDF never leaves your device — there is no upload, no server processing and no data storage.

This is perfect for extracting a single page from a long report, dividing a document into chapters, creating individual invoices from a batch PDF, or removing unnecessary pages by keeping only the ones you need.

Split modes explained

Every Page Separately

Creates one single-page PDF for every page of the original file. A 5-page PDF gives you page-1.pdf through page-5.pdf.

Extract Selected Pages

Enter the page numbers you want, like 1, 3, 5. You get a single new PDF containing exactly those pages, in the order you listed them.

Custom Page Ranges

Enter ranges like 1-3, 4-6, 7-10. Each range becomes its own PDF, named after the range.

Download all as ZIP

When more than one file is generated, grab them all at once in a ZIP archive — and rename the ZIP to whatever you like.

100% private

Your PDF never leaves your device. No upload, no server, no logs, no tracking.

Works on mobile

Fully responsive. Split PDFs from a phone, tablet, or desktop — no app install required.

When would you need to split a PDF?

  • Extract a single page: Pull one page out of a long report, contract or manual for sharing.
  • Divide into chapters: Split a book or manual into chapters or sections for separate distribution.
  • Create individual invoices: Split a batch PDF of invoices into one file per invoice.
  • Remove unwanted pages: Keep only the pages you need and discard the rest.
  • Share selectively: Send only specific pages to different recipients without exposing the whole document.
  • Archive by section: Split a large archive into topic-specific PDFs for easier filing.
