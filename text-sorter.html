What does this Text Sorter do?

                    
This free online text sorter — also called a line sorter, alphabetizer or list sorter — reorders the lines in any block of text according to a rule you choose. Paste a list of names, keywords, URLs, CSV rows or import statements, pick a sort mode, and the tool instantly returns a clean, ordered list.

                    
Unlike a plain alphabetical sort, this tool understands the different ways people need to order data. You can sort alphabetically A-Z or Z-A for names and tags, numerically for ID lists and scores, by line length for keyword research, naturally so item2 comes before item10, or randomly to shuffle a list for sampling. You can also remove duplicate lines at the same time, and trim whitespace or strip empty lines to clean up messy input.

                    
Everything runs locally in your browser. The text you paste never leaves your device, there is no signup, and there are no usage limits. Sort as many lists as you want, as many times as you want.

                


                

                    
How to sort lines of text online

                    
    
                        
  1. Paste your text into the input box, one item per line. You can paste from a spreadsheet, a CSV export, a keyword research tool, a code editor, or any plain-text list.
    2. 
                        
  2. Pick a sort mode using the quick buttons — A→Z, Z→A, Numeric, Natural, Short→Long, Long→Short, Reverse or Shuffle.
    3. 
                        
  3. Set options. Toggle Ignore case, Remove duplicates, Trim whitespace or Remove empty lines to clean the output as it is sorted.
    4. 
                        
  4. Click Sort Lines. The sorted output appears instantly in the right panel, along with statistics on total lines, output lines and duplicates removed.
    5. 
                        
  5. Copy or download. Use Copy Output to put the sorted list on your clipboard, or Download .txt to save it as a file.

Alphabetical vs. natural vs. numeric sort

                    
These three modes look similar but behave differently on numbers. Understanding the difference saves you from sorting the same list twice.

                    
    
                        
  • Alphabetical sort compares text character by character. This means item10 comes before item2, because "1" is less than "2". It is the right choice for names, tags and plain words.
    • 
                        
  • Natural sort understands that digits form numbers. It compares the numeric part as a number and the text part as text, so item2 comes before item10. Use it for file names, version numbers, chapter lists and anything with a number suffix.
    • 
                        
  • Numeric sort parses the leading number in each line and ignores everything else for comparison purposes. It is the right choice for ID lists, score boards and price lists where the number is the sort key.
    • 
                    

                    
If you are not sure which one to use, start with A → Z. If the result looks wrong because numbers are out of order, switch to Natural. If your list is mostly numbers, use Numeric.
