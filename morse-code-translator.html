What does this Morse Code Translator do?


This free online Morse Code Translator converts text to Morse code and Morse code back to text, all in your browser. Type a message and get the dots and dashes instantly, or paste a Morse sequence and read what it says. It covers the full International Morse set — 26 letters, 10 digits, and the most common punctuation marks.


You can also hear the Morse code as audio beeps. The Play button generates the classic dot/dash tones using the Web Audio API, with an adjustable speed slider from 5 WPM to 40 WPM. That makes it useful both for learning and for checking your timing.


Everything runs locally. The text or Morse code you enter never leaves your device, there is no signup, and there are no usage limits. Translate as much as you want, as many times as you want, for personal or commercial projects.

Morse code timing rules


Morse code is not just dots and dashes — the spaces between them matter. Here are the standard timing rules this translator follows when generating audio:






ElementLengthExample



Dot1 unit· (short beep)


Dash3 units— (long beep)


Gap between symbols1 unitBetween dot and dash within a letter


Gap between letters3 unitsBetween letters in a word


Gap between words7 unitsBetween words in a message







The speed slider controls how long one unit lasts. At 15 WPM, one unit is about 80 ms. At 40 WPM it drops to about 30 ms. The exact timing is calculated from the standard Morse code formula: unit = 1200 / WPM milliseconds.

Tips for working with Morse code


    

  • Use dots and dashes, not asterisks. The tool also accepts . and -, but stick to those two characters for the most reliable results.
    • 

  • Separate letters with spaces. A single space between letter groups is the standard. Multiple spaces between letters also work.
    • 

  • Separate words with / or three spaces. Both are supported. Pick whichever is easier for you to type.
    • 

  • Don't worry about case. Morse code has no case — the translator uppercases everything automatically and returns the decoded text in uppercase.
    • 

  • Watch out for lookalike characters. In some fonts, · (middle dot) can look like . (period). Use the ASCII period and hyphen for guaranteed accuracy.
    • 

  • Learn the rhythm, not just the pattern. The audio playback helps you internalise the timing differences between letters — that is what experienced operators listen to.
    •
