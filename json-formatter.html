What does this JSON formatter do?

This free online JSON formatter takes a compact or messy JSON string and re-indents it with proper whitespace so it's easier to read, edit, and debug. At the same time, it validates the JSON and tells you exactly where a syntax error is if the input is invalid.

JSON (JavaScript Object Notation) is a lightweight data-interchange format that's easy for humans to read and write and easy for machines to parse and generate. It's the de facto standard for APIs, configuration files, and data storage. But raw JSON from an API response is usually a single unreadable line — that's where a formatter helps.

The tool supports three indentation styles (2 spaces, 4 spaces, or a tab character), an optional "sort keys A→Z" toggle for consistent output, and a one-click minify mode that strips all whitespace for production. Everything runs locally in your browser, so sensitive JSON never leaves your device.

How to format JSON online

  1. Paste your JSON into the input box. It can be one line, dozens of lines, or an entire API response.
  2. Pick an indentation. Choose 2 spaces, 4 spaces, or a tab. Toggle "Sort keys A→Z" if you want the keys sorted alphabetically at every level.
  3. Click Beautify & Validate. The tool parses, validates, and re-indents the JSON in one shot.
  4. Check the status banner. Green means valid JSON. Red means a syntax error — the exact line number and message will be shown.
  5. Copy or download the result. The download button saves a file named formatted.json.

Need the smallest possible output instead? Click Minify to strip all optional whitespace and produce a compact JSON string.

Beautify vs minify: which should you use?

Beautify and minify are opposite operations, and each has a specific purpose.

Operation What it does When to use it
Beautify Adds newlines and indentation to make JSON readable Debugging API responses, reading config files, code reviews, docs
Minify Removes all optional whitespace to shrink the file Production APIs, embedded JSON, config files shipped to clients

The two operations are reversible — beautifying a minified JSON and then minifying it again gives you back the original (modulo whitespace). Neither operation changes the actual data.

Common JSON syntax errors (and how to fix them)

Most JSON errors come from a small handful of mistakes. Here are the ones this formatter catches most often:

  • Trailing commas: {"a": 1,} is invalid JSON, even though it's valid in JavaScript. Remove the trailing comma.
  • Single quotes: JSON requires double quotes for keys and string values. {'a': 1} is invalid — use {"a": 1}.
  • Unquoted keys: {a: 1} is invalid. Every key must be a double-quoted string.
  • Comments: JSON doesn't allow // or /* */ comments. Remove them before parsing.
  • Missing brackets: An unclosed {, [, ", or } will produce a parse error. Check the end of the file first.
  • NaN and Infinity: These values are not valid JSON. Use null instead.
  • Control characters: Raw newlines or tabs inside string values must be escaped as \n or \t.

When the tool finds an error, it reports the message and the approximate line number so you know where to look.
