What does this Password Strength Checker do?

This free online password strength checker analyses your password and tells you exactly how resistant it is to being cracked. Instead of the vague "weak / medium / strong" labels you see on most signup forms, this tool gives you a transparent breakdown: an entropy score in bits, a crack-time estimate under a realistic attack model, a full character-composition table, and a list of specific weaknesses you can fix.

The analysis runs entirely in your browser. Your password is never sent to a server, never logged, and never stored. You can verify this by disconnecting from the internet — the tool will keep working, because everything it needs is already in the page.

The scoring combines four well-established techniques used by security researchers: entropy estimation (how many bits of randomness your password contains), character-set analysis (which pools of characters you're drawing from), pattern detection (sequential runs, repeats, keyboard walks, dates), and a dictionary check against thousands of the most common passwords.

How to use the Password Strength Checker

  1. Type or paste a password into the input field. You can paste from your clipboard using the paste icon on the right side of the input. The analysis updates live with every keystroke — no button to press.
  2. Use the copy icon to copy the current password back to your clipboard. The copy button is disabled when the field is empty.
  3. Watch the strength meter fill with colour. Red means the password is very weak, orange and yellow mean it's mediocre, green means it's strong. The number next to the label is your overall score out of 100.
  4. Read the four summary cards: length, character-set size, entropy in bits, and estimated time to crack under a realistic GPU attack.
  5. Check the composition list to see which character pools you're drawing from (lowercase, uppercase, digits, symbols) and whether the password is on a common-password list.
  6. Look at the pattern section — if you used sequential characters (abc, 123), repeated characters (aaa), or a keyboard walk (qwerty), it will flag those and recommend a fix.
  7. Use "Generate strong password" if you want a ready-made example that scores well. It creates a random password locally and drops it into the field.

What makes a password strong?

A strong password has three properties, in order of importance:

  1. Length. This is the single biggest factor. Every character you add multiplies the number of possible combinations. A 16-character password is roughly 10 million billion times harder to crack than an 8-character one, even if both use the same character set.
  2. Unpredictability. Random characters are better than patterns. A password like Tr0ub4dor&3 looks complex but is short and based on a dictionary word — a modern cracker will try it early. A password like correct-horse-battery-staple-19 is long and unpredictable, even though it uses only lowercase and hyphens.
  3. Uniqueness. Every account should have its own password. If one site is breached, only that one account is affected — not all of them.

The length vs. complexity trade-off

Old advice said "use uppercase, lowercase, digits, and symbols." That's not wrong, but it's incomplete. Length dominates. Here's the rough math:

Password style Example Entropy (approx) Crack time
8 lowercaseabcdefgh~37 bitsSeconds
8 mixedaB3$xY9!~52 bitsHours
12 mixedaB3$xY9!pQ2#~78 bitsCenturies
16 mixedaB3$xY9!pQ2#mN7&~104 bitsTrillions of years
4 random wordscorrect-horse-battery-staple~103 bitsTrillions of years
5 random wordscorrect-horse-battery-staple-vega~128 bitsEffectively forever

The key insight: a long passphrase of random words is easier to remember than a short string of random symbols, and often just as strong. This is why security experts increasingly recommend passphrases over password complexity rules.

Password entropy explained

Entropy is measured in bits. Each additional bit doubles the number of possible passwords an attacker has to try. Formally, entropy is calculated as:

Entropy (bits) = Length × log₂(Character set size)

In practice, this tool also applies penalties for predictable patterns, because a password like aaaaaa123456 has a large character-set size but is trivially guessable. The pattern detection step reduces the effective entropy accordingly.

How the crack time estimate works

The crack time estimate assumes an attacker who knows your password's exact length and character-set composition, and who can try 10 billion guesses per second. That figure is a realistic upper bound for a modern multi-GPU cracking rig attacking a fast hash like MD5 or SHA-1.

The estimate is deliberately conservative. Real-world attackers face additional obstacles:

  • Rate limiting. Most online services lock accounts after a handful of failed attempts, which reduces the effective guess rate to a few per minute.
  • Slow hashing. Sites using bcrypt, scrypt, or Argon2 hash passwords thousands of times per guess, which cuts the attacker's rate by three or four orders of magnitude.
  • Dictionary attacks. Attackers don't try every combination in order — they try common passwords, dictionary words, and known patterns first. This makes some passwords crack far faster than entropy alone would suggest, which is why pattern detection matters.
  • Leaked databases. If your password has ever appeared in a breach, it's on a list. Modern attackers try those lists first. That's why uniqueness matters as much as strength.

The estimate shown here assumes the attacker is using an offline brute-force attack against a fast hash, which is the worst realistic case. If your password survives that, it will survive everything else.

Common password mistakes to avoid

  • Using a dictionary word with a capital letter and a number at the end. Password1, Summer2024, Welcome123 — these are the first things a cracker tries.
  • Reusing the same password across sites. One breach, and every account is compromised. Use a password manager to keep every password unique.
  • Using personal information. Names, birthdays, pet names, and addresses are all guessable from social media and public records.
  • Keyboard walks. qwerty, asdfgh, 1qaz2wsx — patterns like these are in every cracker's dictionary.
  • Sequential numbers. 123456, 111111, 0000 are the most common passwords in the world, year after year.
  • Short passwords. Anything under 12 characters is now considered weak, regardless of complexity.
  • Writing it down on a sticky note. If you need to write it down, use a password manager instead — it's more secure and more convenient.
  • Changing passwords on a schedule. Modern guidance says only change when there's a reason (breach, suspicion, shared device). Frequent forced changes lead to weaker passwords, not stronger ones.

Password best practices in 2026

1. Use a password manager

This is the single highest-impact change you can make. A password manager generates and stores a unique, high-entropy password for every account, so you only need to remember one strong master password. Bitwarden, 1Password, KeePass, and Dashlane are all excellent. Most have free tiers.

2. Prefer passphrases for the master password

Your password manager's master password is the only one you need to remember. Make it a long passphrase of 5–6 random words, not a "complex" short password. The EFF's diceware word list is a great source of random words.

3. Enable two-factor authentication everywhere

Even the strongest password can be phished or leaked. Two-factor authentication (2FA) means an attacker needs more than just your password. Use an authenticator app (Aegis, 1Password, Authy) rather than SMS where possible, and prefer hardware keys (YubiKey) for critical accounts.

4. Check for breaches

Services like Have I Been Pwned let you check whether your email or password has appeared in a known breach. If it has, change it everywhere you used it.

5. Never reuse passwords

This is the rule that matters most after using a manager. Every account gets its own password. If one is compromised, the rest stay safe.
