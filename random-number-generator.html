What does this Random Number Generator do?

This free online random number generator produces numbers in any range you specify, using the browser's Web Crypto API — the same cryptographic engine browsers use to secure HTTPS connections and generate authentication tokens. Every number is drawn from the operating system's entropy pool, so it cannot be predicted or reproduced.

Unlike tools that rely on Math.random(), which is a deterministic pseudo-random generator that can produce subtly skewed distributions, this tool uses crypto.getRandomValues() combined with rejection sampling to eliminate modulo bias. That means every value in your range is exactly equally likely — which matters for raffles, lottery draws, statistical sampling, and any scenario where fairness needs to be verifiable.

You can generate integers or decimals, draw unique numbers without repeats, produce up to 1,000 numbers in a single batch, and sort the results ascending or descending. Everything runs locally in your browser; nothing is ever uploaded.

How to generate random numbers

  1. Set your range: Enter a minimum and maximum value. Negative numbers and decimals are supported.
  2. Choose how many: Pick how many numbers you want in this draw — anything from 1 to 1,000.
  3. Choose decimals (optional): Select 0 for integers, or 1–6 for decimal places. The tool scales internally so every step is equally likely.
  4. Enable Unique (optional): Turn on unique mode to draw without replacement — perfect for raffles, lottery picks, and team selection.
  5. Click Generate: Your numbers appear instantly. Copy them to the clipboard or download them as CSV.

Your recent draws are saved in a history panel on the right so you can review past results or re-copy them.

Cryptographically secure vs. pseudo-random: why it matters

Not all random number generators are equal. The distinction matters whenever fairness needs to be defensible — for a public raffle, a lottery draw, or a research study, the mechanism itself has to be trustworthy.

How the generator produces unbiased numbers

Two techniques work together to guarantee fairness: rejection sampling and the Fisher–Yates shuffle.

Rejection sampling

A naive approach to generating a number in a range is random() % range. This is subtly biased: if the range doesn't divide evenly into the generator's output space, smaller values appear slightly more often. This tool instead draws a full-width random value and rejects any result that would fall outside the largest multiple of the range, then re-draws. The result is exactly uniform.

Fisher–Yates shuffle

When you enable Unique mode, the tool needs to draw numbers without replacement. A naive "keep drawing until you get a new one" approach slows down badly as the pool shrinks. Instead, the tool builds the full list of possible values, then applies the Fisher–Yates shuffle — an unbiased algorithm that gives every permutation equal probability — and takes the first N items. Fast, fair, and predictable.

Both techniques are used by cryptographic libraries and statistics tools, and both run in a few milliseconds in your browser.
