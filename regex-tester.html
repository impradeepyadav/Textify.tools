What does this Regex Tester do?

A regex tester is a development tool that lets you write a regular expression, run it against a test string, and see the results immediately. Instead of guessing whether your pattern works, you get live feedback: every match is highlighted in the test string, and each match's position, length, and capture groups are shown in a structured list.

This tool uses the JavaScript regex engine (ECMAScript), which is the same engine used in browsers and Node.js. If your pattern works here, it will work in your JavaScript code. It supports the full modern feature set: named capture groups, lookbehind assertions, Unicode property escapes, sticky matching, and all six regex flags (g, i, m, s, u, y).

Everything runs locally in your browser — the pattern and test string never leave your device. No signup, no server round-trip, no logging. The results update live as you type, so you can iterate on a pattern without pressing a button.

How to use the Regex Tester

  1. Enter your pattern in the regular expression input. The leading and trailing slashes are provided for you — just type the pattern itself.
  2. Select your flags using the chips below the input. The g flag is on by default so all matches are found. Click any flag to toggle it on or off.
  3. Paste or type your test string in the textarea. Matches will highlight automatically as you type.
  4. Review the matches in the right panel. Each match shows its index, start position, matched value, and any capture groups or named groups.
  5. Switch to Replace mode if you want to test a replacement. Enter the replacement string (using $1, $2, or $<name> for groups) and see the transformed output.
  6. Load a common pattern from the chips at the bottom of the input panel if you need a starting point.

A note on HTML parsing: regex is not the right tool for parsing nested HTML or XML. For simple cases like extracting attribute values or matching a known tag pattern, it works fine. For anything with nested structures, use a proper parser (like DOMParser in the browser or a server-side HTML parser).

The six JavaScript regex flags

Flags modify how a regular expression behaves. They're written after the closing slash — for example, /pattern/gi. You can combine any flags, and this tool lets you toggle each one independently.

Flag Name What it does
gGlobalFind all matches instead of stopping after the first. Without g, exec() returns only the first match.
iIgnore caseMakes matching case-insensitive. /hello/i matches "Hello", "HELLO", and "hello".
mMultilineMakes ^ and $ match the start and end of each line, not just the whole string.
sDotallMakes . match newline characters too. Without s, . stops at line breaks.
uUnicodeEnables full Unicode mode. Required for \p{...} property escapes and correct handling of surrogate pairs.
yStickyMatches only at the position indicated by lastIndex. Useful for tokenizing input sequentially.
