What does this Line Counter do?

                    
This free online line counter tells you exactly how many lines are in any block of text. Paste a document, a code file, a CSV export, a log file or a chat log, and it instantly shows you the total line count, how many lines actually contain content, and how many are blank. It is effectively a browser-based wc -l equivalent that works on Windows, Mac, Linux, Android and iOS.

                    
Beyond a simple count, this text line counter also gives you useful statistics about your lines: the longest line, the shortest line, average line length, total word count and total character count. If you are working with formatted data — log files, source code, CSV exports or subtitle files — these details help you spot anomalies and understand the shape of your text at a glance.

                    
Everything runs locally in your browser. The text you paste never leaves your device, there is no signup, and there are no usage limits. Count as many lines as you want, as many times as you want, for personal or commercial use.

How line breaks affect your count

                    
Different operating systems and editors use different characters to represent a line break. This matters when you are counting lines, because a mismatch can throw off your count.


                    

                        

                            
                                

                                    Line break type
                                    Characters
                                    Used by
                                    Effect on line count
                                

                            
                            
                                

                                    LF (Line Feed)
                                    \n
                                    Unix, Linux, macOS
                                    Each LF starts a new line
                                

                                

                                    CRLF (Carriage Return + Line Feed)
                                    \r\n
                                    Windows
                                    Each CRLF pair starts a new line — counted as one line break
                                

                                

                                    CR (Carriage Return)
                                    \r
                                    Classic Mac OS (pre-OS X)
                                    Each CR starts a new line — rarely seen today
                                

                            
                        

                    


                    
This tool normalizes all three types before counting, so you get the same line count regardless of where the text came from. If you need to convert between line break types, use our Line Break Converter.


                    
One important detail: a single trailing newline is treated as a line terminator, not as an extra empty line. This matches the behaviour of wc -l and most editors. For example, the text "apple\nbanana\n" has two lines — "apple" and "banana" — not three. And "apple\nbanana" also has two lines, because the last line is counted even without a trailing newline.
