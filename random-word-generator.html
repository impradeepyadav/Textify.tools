Word list & randomization


We built a hand-picked dictionary of frequently used English words across various difficulty levels, from basic to advanced. The pool contains common nouns, verbs, adjectives, and adverbs, and holds over 1,000 words after de-duplication — all lowercase, letters only, no proper nouns or punctuation.


Each word is selected using JavaScript's cryptographic random number generator (crypto.getRandomValues) with rejection sampling, which removes the modulo bias you get from a naive Math.random() approach. The result is unbiased and unpredictable — you can reuse the generator any number of times and it will never fall into a visible pattern.


Filters are applied before selection, so the pool shrinks as you narrow the length range or set a starting prefix. The Pool stat above the output always shows exactly how many words are eligible under your current filters, so you know whether a request for 200 words can actually be satisfied.





If you enable Avoid duplicates and ask for more words than the filtered pool contains, the generator returns every available unique word rather than repeating any. The status line above the output tells you when this happens, so you can widen the length range or remove the starting-letter filter and try again.
