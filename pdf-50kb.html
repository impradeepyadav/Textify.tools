What does this PDF compressor do?

This free online tool shrinks a PDF file down to a target size — 50KB by default, but you can type any size you need from 5KB to 10MB. You drop a PDF, enter your target, and the tool automatically finds the best combination of image quality and rendering resolution that fits under your limit. No upload to a server, no queue, no signup, no watermark.

Under the hood, it renders each page to a canvas at a controlled resolution, re-encodes each page as a compressed JPEG, and rebuilds a fresh PDF from those images. This is the same technique used by every serious browser-based PDF compressor, and it's the most reliable way to hit a tight file-size target without server-side processing.

When you request a specific size, the tool runs a binary search over JPEG quality levels and falls back to lower render resolutions if needed to get as close as possible while keeping the pages readable. If your PDF can't reach the target without becoming a blurry mess, you'll get the smallest file the tool can produce, plus a clear note about what happened.

How to compress a PDF

  1. Drop your PDF into the upload area, or click Browse files to pick one. The file stays on your device the whole time.
  2. Set the target size. The input starts at 50 KB, but you can type any value between 5 KB and 10,000 KB. Quick-pick chips (25 KB, 50 KB, 75 KB, 100 KB, 200 KB, 500 KB, 1 MB, 2 MB) let you one-click common sizes.
  3. Click Compress PDF. A progress bar shows each stage — loading, rendering, searching for the best quality, and saving.
  4. Check the result card. You'll see the original size, the compressed size, and the percentage saved.
  5. Download the compressed PDF using the download button. The filename is your original name with -compressed appended.

Tip: If the first attempt doesn't hit your target exactly, click Try Again and adjust the target. The tool always gives you the smallest readable file it can produce at your chosen quality level.

How browser-based PDF compression actually works

A PDF is a structured document — it contains text, fonts, images, vector graphics, metadata, and a complex internal object graph. Reducing its size is not a single operation. Server-side tools like Ghostscript do a lot of low-level work, but browsers can't do all of that. Here's what this tool actually does:

  1. Parse the PDF. The pdf.js library reads the file, extracts the page structure, and gives us a list of pages with their dimensions.
  2. Render each page to a canvas. Every page is drawn onto an HTML canvas at a controlled resolution (a scale factor applied to the page's natural size).
  3. Encode as JPEG. Each canvas is converted to a JPEG blob using the browser's built-in JPEG encoder. This is the step where compression actually happens — lower quality = smaller file, fuzzier image.
  4. Rebuild a new PDF. The pdf-lib library creates a fresh PDF, embeds each JPEG as a full-page image, and writes it out.
  5. Binary search for the target. When you request a specific size (50 KB, 75 KB, 1 MB, whatever), the tool tries several quality levels and picks the highest quality that fits under the target. If even the lowest quality doesn't fit, it drops the render resolution and tries again.

The trade-off is that text becomes non-selectable in the compressed output — it's an image of the text. For upload portals and print use, that's almost always fine. If you need searchable text in the compressed PDF, no purely browser-based tool can do that yet; you'd need a server-side OCR pass.

Tips for getting the best result

  • Start with a clean source. A phone-scanned PDF with a dark background will compress worse than a clean white scan. Use your scanning app's "document" mode, not "photo" mode.
  • Fewer pages = smaller file. If you only need the first page of a long document, remove the extra pages before compressing.
  • Don't recompress an already-compressed PDF. If you already ran this file through a compressor, running it again will only lose more quality without much size benefit.
  • Start with 50 KB, then adjust. If the preview looks unreadable at 50 KB, try 75 KB or 100 KB. If the portal accepts larger files, go higher.
  • Check the preview. The first-page preview shows you exactly what the output looks like. If the text is unreadable, try a larger target size.
  • Keep the original. The compressed PDF replaces selectable text with images. Always keep the original file — you may need it later for editing.
