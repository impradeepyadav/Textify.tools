What does this PDF Unlock tool do?

This tool removes password protection and encryption from a PDF you have the password for — entirely in your browser. It decrypts the document, strips the encryption dictionary, and saves a clean, unencrypted copy that opens without any password in any PDF viewer.

The tool uses @pdfsmaller/pdf-decrypt, a purpose-built library that supports AES-256 (PDF 2.0 standard) and RC4 (legacy) encryption. It auto-detects the algorithm, accepts both user and owner passwords, and validates the password before decrypting — a wrong password throws a clear error instead of silently producing a corrupted file.

Everything runs locally. Your PDF never leaves your device — there is no upload, no server processing, and no data storage. Close the tab and it's gone.

How to remove a password from a PDF

  1. Upload your PDF: Drag and drop a password-protected PDF into the upload zone, or click to browse your device.
  2. Enter the password: Type the user or owner password for the PDF. The tool will verify it before decrypting.
  3. Click Unlock PDF: The tool decrypts the document and removes all encryption and permission flags.
  4. Download: Click Download Unlocked PDF to save the file. It will open without any password in any PDF viewer.

When would you need to unlock a PDF?

  • Your own forgotten password: You locked a PDF months ago and can no longer remember the password.
  • Permission restrictions: A PDF you own blocks printing or copying, but you have the owner password and want to remove those limits.
  • Editing a document: You need to modify or fill in a PDF that was locked against editing.
  • Archiving: Remove encryption from old documents so they can be indexed and searched more easily.
  • Sharing internally: A document that requires a password for external use is annoying for internal team members.
  • Printing: Some locked PDFs block printing entirely, even for the person who owns the document.
