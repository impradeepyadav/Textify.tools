What does the Markdown Table Generator do?

This free online tool builds GitHub Flavoured Markdown (GFM) pipe tables visually. Instead of typing pipes and dashes by hand, you fill in a spreadsheet-style grid. Every change updates the Markdown output and rendered preview instantly.

You can add or remove rows and columns at any time, set alignment for each column individually, toggle whether the first row is a header, and control whether columns are padded for readability in the raw Markdown. Pipes inside cell content are escaped automatically so your table stays valid even if a cell contains a pipe character.

Everything runs locally in your browser. Your table data never leaves your device — no server upload, no logging, no tracking. Close the tab and it's gone.

How to build a Markdown table — step by step

  1. Fill in the grid: Click any cell in the table builder and type. The first row is the header by default — turn the header toggle off if you don't want one.
  2. Add or remove rows: Use the + Row button to add a row at the bottom. Click the trash icon at the left of any row to remove it.
  3. Add or remove columns: Use the + Column button to add a column at the end. Click the trash icon at the top of a column to remove it.
  4. Set alignment: Above each column header, click the left, centre, or right alignment icon. The choice is reflected in the separator row of the Markdown.
  5. Copy or download: Use the Copy Markdown button to put the output on your clipboard, or download it as a real .md file.

The Markdown output and rendered preview update as you type, so you can see exactly what you'll get before pasting it into GitHub, GitLab, or any Markdown editor.

Markdown table syntax reference

A GFM pipe table is made of three parts: a header row, a separator row that defines alignment, and one or more data rows. Here's the syntax the generator produces:

| Name  | Age | City      |
|-------|:---:|-----------|
| Alice | 30  | New York  |
| Bob   | 25  | London    |

The separator row uses colons to indicate alignment:

Alignment Separator syntax Rendered result
Left (default):------- or --------Text aligned to the left
Centre:------:Text aligned to the centre
Right-------:Text aligned to the right

You don't need to remember any of this — the generator writes the correct syntax for you based on the alignment icons you click.

Where can you use the generated Markdown?

  • GitHub: README files, issues, pull requests, wikis, and comments all render GFM pipe tables.
  • GitLab, Bitbucket, Gitea: Same syntax, same result.
  • Stack Overflow and Stack Exchange: Tables are supported in questions and answers.
  • Reddit: New Reddit uses a similar pipe table syntax for posts and comments.
  • Discord: Tables render in embeds and some message types.
  • Notion and Obsidian: Both convert pipe tables into native table blocks.
  • Static site generators: Jekyll, Hugo, Eleventy, Astro, and MkDocs all render GFM tables from Markdown files.
  • Documentation tools: Docusaurus, VitePress, and MkDocs Material include GFM table support out of the box.
  • Note apps: Bear, Ulysses, iA Writer, and most Markdown editors support pipe tables.

Tips and best practices

  • Turn on column padding for source readability. The raw Markdown is much easier to read when columns are aligned. Turn it off if you're optimising for bytes.
  • Escaping pipes. If a cell needs a literal | character, write \|. The generator does this for you when you type a pipe into a cell.
  • Avoid complex formatting inside cells. Most Markdown renderers support inline code, bold, italic, and links inside cells, but not lists, blockquotes, or multi-line content. Keep cells short.
  • Use header row unless you're building a data matrix. A header row makes the table much easier to scan.
  • Don't use tables for layout. Markdown tables are for tabular data, not for positioning. Use headings, lists, and paragraphs for content structure.
  • Keep column counts reasonable. Tables with many columns get hard to read on narrow screens. If you need more than 6 or 7 columns, consider splitting into multiple tables.
  • Need to convert CSV to a Markdown table? Use the CSV to Text tool to turn a spreadsheet into plain rows, then paste into this builder.
  • Need the reverse? Try the Markdown to HTML tool to render a table as HTML.

Privacy, accuracy, and limits

Privacy: Nothing you type into the table builder is sent to a server. Everything runs in your browser using JavaScript. There is no upload, no analytics event containing your content, and no server-side log.

Accuracy: The generator produces GitHub Flavoured Markdown pipe tables, the most widely supported dialect. Alignment is stored in the separator row using colons, and pipes inside cell content are escaped automatically.

Limits: There is no hard limit on row or column count, but very large tables (hundreds of rows) may become slow to edit on older devices. A built-in safety guard warns you before generating output that could freeze the tab.
